# PPM

Kalkulator zapotrzebowania kalorycznego i składu ciała.

Aplikacja jest zaszyfrowana (AES-256-GCM, klucz z hasła przez PBKDF2-SHA256) i otwiera się dopiero po wpisaniu hasła.
Dane klientów nie są przechowywane na serwerze – zostają na urządzeniu użytkownika i w zapisanych przez niego plikach.

Adres: https://maciekpacynski.github.io/ppm/ppm.html
